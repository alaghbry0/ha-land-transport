# HA للنقل البري — HA Land Transport

**نموذج أولي تفاعلي كامل (Interactive Prototype)** لتطبيق نقل بري محلي داخل المملكة العربية السعودية بنمط أوبر/كريم — واجهة عربية بالكامل (RTL)، خريطة OpenStreetMap بلا مفاتيح API، ومزامنة لحظية بين وضعي الراكب والكابتن في نفس الجلسة.

مبني على قالب [`flutter-sandbox-template`](https://github.com/alaghbry0/flutter-sandbox-template) (Flutter 3.47 stable · Dart 3.13) بأسلوب التشغيل والاختبار نفسه المستخدم في [`simple-invoice-manager`](https://github.com/alaghbry0/simple-invoice-manager).

| الطبقة | التقنية |
|---|---|
| الإطار | Flutter 3.47.7 stable · Dart 3.13 |
| الواجهة | Material 3 — كحلي داكن `#0F172A` + أخضر زمردي `#10B981` |
| الخط | IBM Plex Sans Arabic (أصول خطوط مرفقة — عربي عصري RTL) |
| الخريطة | `flutter_map` 8.x + بلاطات OpenStreetMap المجانية — **بلا مفاتيح API مدفوعة** |
| الإحداثيات | `latlong2` (Haversine للمسافات داخل التطبيق) |
| الحالة | `ChangeNotifier` Singleton واحد (`AppService`) يبث التغييرات لحظياً للوضعين |
| المنصات | ويب (معاينة الـ sandbox) · أندرويد (APK عبر CI) · iOS |
| الجودة | `flutter analyze` — صفر مشاكل |

## المزايا

### 🧑‍💼 دورة الراكب
- خريطة تفاعلية متمركزة في الرياض مع علامات واضحة (انطلاق/وجهة/سيارة الكابتن).
- بطاقة سفلية أنيقة لتحديد نقطة الانطلاق والوجهة مع **أزرار اختصار سريعة**: مطار الملك خالد، بوليفارد سيتي، مركز الملك عبدالله المالي (KAFD)، العليا.
- اختيار فئة المركبة (**اقتصادي / عائلي / VIP**) مع السعر التقديري بالريال والمسافة والوقت المتوقع.
- متابعة تفاعلية للرحلة: جاري البحث عن كابتن ← الكابتن في الطريق (بياناته وسيارته ولوحته) ← وصل ← بدأت الرحلة ← الوصول والتقييم بالنجوم.

### 🚕 دورة الكابتن
- **دخول سريع** بحساب افتراضي (كابتن خالد الحربي) أو **تسجيل كابتن جديد** (الاسم، جوال سعودي `05xxxxxxxx` مع تحقق، نوع المركبة، رقم لوحة سعودية).
- لوحة تحكم علوية: حالة الاتصال (متاح/غير متاح) + **الأرباح اليومية** + عدد الرحلات + التقييم.
- بطاقة طلب واردة بارزة (الموقع، الوجهة، المسافة، القيمة بالريال) مع **قبول/رفض**.
- إدارة مراحل الرحلة خطوة بخطوة: وصلت لموقع العميل ← بدء الرحلة ← إنهاء وتحصيل **نقداً / مدى / Apple Pay** (وهمياً).

### 🔄 مبدل الوضع الفوري
شريط علوي عائم دائم يتيح التبديل اللحظي بضغطة واحدة بين «وضع الراكب» و«وضع الكابتن» مع:
- شارة عدد الطلبات الواردة على زر الكابتن.
- انتقالات سلسة عبر `AnimatedSwitcher`.
- **مزامنة فورية**: اطلب رحلة كراكب، بدّل للكابتن تجد الطلب أمامه فوراً، اقبله وستنعكس المراحل مباشرة في واجهة الراكب.

## معمارية المعاينة في الـ Sandbox

المنفذ 3000 هو المنفذ الظاهر الوحيد — يُخدَم بناء الويب من `build/web` عبر `scripts/static-server.mjs`:

```
تعديل lib/**  →  bash scripts/build-web.sh --release  →  تحديث المعاينة على /
```

## التشغيل السريع

```bash
git clone https://github.com/alaghbry0/ha-land-transport.git && cd ha-land-transport
bash scripts/bootstrap-flutter.sh      # إن لم يكن Flutter SDK مثبتاً (~3-4 دقائق)
flutter pub get
flutter run                            # جهاز/محاكي محلي

# أو حلقة معاينة الويب:
bash scripts/build-web.sh --release --base-href /
node scripts/static-server.mjs         # يخدم build/web على المنفذ 3000
```

## CI/CD

`.github/workflows/android-apk.yml` — بأسلوب simple-invoice-manager:

- **دفع main** = بوابات فقط (`flutter analyze` صفر مشاكل).
- **وسم `v*`** = بوابات + بناء APK (matrix: `arm64` للهواتف الحديثة + `universal`) + نشر **GitHub Release** بالملفات.
- **تشغيل يدوي** = arm64 حصراً (تدفئة الكاش) مع خيار بناء الشاملة.
- `versionCode` = رقم التشغيل (متصاعد حصراً).

```bash
git tag v1.0.0 && git push origin v1.0.0   # ← يشعل بناء APK + Release
```

## القيود المعروفة (نموذج أولي)

- البيانات وهمية بالكامل في الذاكرة (Mock) — لا خادم خلفي ولا حسابات حقيقية.
- موقع سيارة الكابتن على الخريطة محاكاة ثابتة قرب نقطة الانطلاق.
- مسار الرحلة خط مستقيم بين النقطتين (لا routing فعلي).
- الدفع (مدى/Apple Pay) وهمي — مجرد تسجيل طريقة الدفع في ملخص الرحلة.
